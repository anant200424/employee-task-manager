# Employee Task Manager

## Project Purpose

Employee Task Manager is a training project built using Next.js and TypeScript. The purpose of this project is to learn modern frontend development practices, clean project structure, reusable components, and Git workflow.

---

## Tech Stack

- Next.js
- React
- TypeScript
- CSS
- Git & GitHub

---

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Move to the project directory:

```bash
cd employee-task-manager
```

Install dependencies:

```bash
npm install
```

---

## Run the Project

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```

---

## Basic Development Rules

- Use TypeScript for all new files.
- Keep components small and reusable.
- Organize code using the project folder structure.
- Do not duplicate code.
- Write meaningful Git commit messages.
- Test the application before committing changes.
- Follow clean coding practices.
